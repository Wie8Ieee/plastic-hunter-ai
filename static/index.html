🌊 About Plastic Hunter AI

AESS Sustainability Hackathon 2026 — Track 11: Sustainable Sonar Systems for Marine & Climate Protection

🎯

Problem

Marine plastic pollution affects over 800 species and costs $13B annually in environmental damage. Manual detection is too slow and expensive to scale.

🤖

Solution

AI-powered Computer Vision system that automatically detects plastic pollution in marine images and videos, generating real-time pollution maps.

📈

Impact

Enables faster response times, precise pollution mapping, and data-driven cleanup prioritization — protecting marine ecosystems at scale.

System Architecture
Image/Video Input → FastAPI Backend → YOLOv8 Detection Model → SQLite Storage → Leaflet.js Map + Chart.js Dashboard
Tools: Python · FastAPI · YOLOv8 (Ultralytics) · OpenCV · SQLite · Leaflet.js · Chart.js

AI Usage Disclosure

This project uses AI assistance for code generation and documentation structuring. All outputs were reviewed and validated by the team. The detection model simulates YOLOv8 behavior — in production, replace detector.py with a model trained on real marine plastic datasets (TACO, PlasticLitter).
